# Titanic Data Analysis with Pandas

A beginner-level data analysis project using Python and Pandas on the Titanic dataset from Kaggle.

## Objectives
- Load and inspect real-world CSV data.
- Identify missing values.
- Calculate average passenger age.
- Analyse survival rates by passenger class and gender.
- Filter and export surviving passengers.

## Technologies
- Python
- Pandas

## Dataset
[Titanic - Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic/data)

## Output
`survivors.csv` — contains records of passengers who survived.

## Run
```bash
pip install pandas
python pandy.py
```
